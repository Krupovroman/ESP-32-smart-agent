_Обновлено: 18 октября 2026, ночь. Плата: Waveshare ESP32-S3-Touch-LCD-1.85 rev 2.1 на COM7._

## Стоимость

Ответ ИИ ≈ $0.0002–0.0003, озвучка ≈ $0.0005–0.002 за ответ. Ключ: лимит $250, потрачено ≈ $0.01.

## Как откатиться

1. **Заводская прошивка**: `python -m esptool --port COM7 write-flash 0 backups/factory_full_16MB.bin` (подробно — `backups/README.md`).
2. **Любая прошлая версия кода**: git-теги `m1`, `m2`, `v0.5-rc1` … (`git checkout <тег>`, затем `tools\idf.ps1 -p COM7 flash`).
3. **На самой плате**: два слота прошивки; если новая версия не проходит самопроверку при загрузке — плата сама возвращается к предыдущей. Подробно — `docs/rollback.md`.
4. **Если плата не отвечает по USB**: зажать BOOT, нажать и отпустить RESET, отпустить BOOT — режим прошивки.

## Ночная тишина

Пока ты спал, громкость стоит **0** и включён режим «только текст». Чтобы вернуть голос:
`python tools/dev.py run "set volume 60" "set text_only 0"` — или в настройках на самой плате.

## Нужны твои решения

1. **Заголовки дугой по краю экрана** («Настройки», «Ключ API» …) нарисованы повёрнутыми буквами — выглядят «круглее», но буквы чуть неровные. Оставить или сделать прямые заголовки?
2. **Хрип динамика**: проверить на громкости 40 % и подстроечником громкости на плате (если он выкручен на максимум).
3. **Пароль root на сервере** — смени (`passwd`), он засветился в чате. Мой доступ по ключу не пострадает; отозвать его — удалить строку `claude-round-assistant-proxy` из `/root/.ssh/authorized_keys`.
4. **Ключ OpenRouter** тоже засветился в чате — после проверки создай новый и введи его через «Настройка по QR» с телефона.

## Инструменты разработчика

- `tools\idf.ps1 build` / `tools\idf.ps1 -p COM7 flash` — сборка и прошивка.
- `python tools/dev.py <команда>` — консоль платы (скриншоты `shot`, нажатия `tap`, настройки `get/set`, `ai ask`, `ptt down/up`, `app state` …).
- `python tools/smoke.py` — автотест на плате без участия человека (15 проверок).
